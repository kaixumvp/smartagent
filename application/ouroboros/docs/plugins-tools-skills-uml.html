统一协议

Plugin 统一提供 manifest、生命周期和 invoke 能力，Registry 不区分 tool 与 skill 的执行入口。

适配边界

旧式 Tool.run() 通过 ToolAsPlugin 转换为 Plugin.invoke()，保持向后兼容。

Skill 形态

Skill 通过 type 区分 prompt、function、flow、agent 四种具体实现。

LLM 命名

tool 使用原名；skill 通过 skill_ 前缀命名，避免函数名冲突。
