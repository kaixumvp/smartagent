
# Capability Registry v0.2.0

> MCP Provider & Tool Registration

## 目标

接入外部 MCP Server，但不执行 Tool。

> Registry 保存注册信息（Registration），真正调用仍然走 MCP。

---

## 架构

MCP Server
      │
 listTools()
      │
      ▼
  MCP Adapter
      │
      ▼
 Tool Registration
      │
      ▼
 PostgreSQL

---

## 新增对象

### Provider

| 字段 | 说明 |
|------|------|
| id | Provider 主键 (UUID) |
| name | Provider 名称 |
| endpoint | MCP 地址 |
| credential_ref | 密钥引用（不落明文） |
| status | online/offline（派生） |
| last_sync_at | 最后同步 |

### Tool Registration

| 字段 | 说明 |
|------|------|
| id | Tool 主键 (UUID) |
| provider_id | Provider |
| remote_tool_name | MCP 原始名称 |
| display_name | 本地名称 |
| description | 描述 |
| tags | 本地标签 |
| lifecycle_state | draft / active |
| manifest | Tool 元数据 |
