
# Capability Registry v1.0

> Enterprise Tool Registry

## 项目定位

Capability Registry 是 Agent 平台的 Control Plane。

负责：

- Tool Registration
- MCP Provider
- Tool Metadata
- Discovery
- Permission Metadata
- Catalog

不负责：

- Tool Runtime
- Skill
- Workflow
- LLM

---

## 最终架构

Web Console
      │
 REST API
      │
Capability Registry
      │
 ├── Tool Service
 ├── Provider Service
 ├── Discovery
 └── Sync Service
      │
 PostgreSQL

> 同步控制流（与存储流分离）：

Sync Service ──► MCP Adapter ──► External MCP Server (listTools / schema)
      │                              │
      └──────────── 写回 ────────────┘
                   │
               PostgreSQL

Architecture

- MCP Tool 本地注册、远程执行
- Provider 与 Tool 解耦
- 鉴权：Admin 登录 + Runtime API Key + Provider 密钥加密存储
