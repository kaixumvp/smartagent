
# Capability Registry v0.1.0

> Local Tool Registry（MVP）

## 项目目标

建立最小可运行的 Tool 管理中心。

### 包含

- Tool CRUD
- Tool Catalog
- Tool Manifest
- PostgreSQL
- Web 管理页面

### 不包含

- MCP
- Discovery
- Permission
- Skill
- Runtime

---

## 系统架构

Web Console
        │
     REST API
        │
    FastAPI
        │
 Tool Service
        │
 PostgreSQL

---

## 数据模型

| 字段 | 说明 |
|------|------|
| id | Tool 主键 (UUID) |
| display_name | 展示名称 |
| description | 描述 |
| lifecycle_state | draft / active |
| manifest | JSONB |

> `version` 存于 manifest.identity.version，不作为独立列。
