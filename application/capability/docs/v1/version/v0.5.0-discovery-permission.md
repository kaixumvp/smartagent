
# Capability Registry v0.5.0

> Discovery + Permission

## 目标

让 Registry 真正具备 Tool 搜索能力。

---

## 新增功能

### Discovery

- Name
- Description
- Keywords
- Tags

> Intent / 语义检索推迟到 v3.0「Vector Discovery」，v1 仅做确定性关键词/标签匹配。

### Permission

每个 Tool 配置一个 Permission Group。

例如：

ERP_READ
OCR_USE
EMAIL_SEND

---

## Discovery 流程

User Query
      │
      ▼
加权打分（name > description > keywords > tags）
      │
      ▼
过滤 active + enabled
      │
      ▼
Top K Tool

---

## Discovery API

POST /discover

Request

{
  "query":"查询员工",
  "top_k":5
}

Response

{
  "items":[]
}
