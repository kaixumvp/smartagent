# SmartAgent 多项目版本规划总览

> 本文只汇总仓库内各项目的版本基线与交付边界。版本号唯一真源是仓库根 [VERSIONS.md](../VERSIONS.md)；
> 单个项目的功能细节分别见对应子目录路线图。

## 1. 项目版本轴

| 项目 | 当前版本/基线 | 版本规划 | 发布边界 |
|---|---|---|---|
| PlatformAgent（业务后端 + Console） | 0.3.0 功能基线 | [PlatformAgent 版本规划](./platformagent/版本规划.md) | Console 随平台交付；`package.json` 的 0.1.0 不是独立 Console 发版 |
| Ouroboros（Agent 框架） | 2.0.0 | [Ouroboros 版本规划](./ouroboros/版本规划.md) | 独立 SemVer；框架不依赖业务 API/DB |
| Capability Registry | 0.3.0 | [Capability 版本规划](./capability/version-roadmap.md) | 独立服务；与 PlatformAgent 通过 HTTP 集成 |

三条版本轴独立演进，版本号不可相互比较。Ouroboros 是 PlatformAgent 的 Python 路径依赖；
Capability Registry 则独立部署，不共享 PlatformAgent 的 Python 包或数据库。

## 2. PlatformAgent 里程碑

| 版本 | 主题 | 状态 |
|---|---|---|
| 0.1.0 | 单 Agent 最小闭环与基础工具 | 已交付 |
| 0.2.0 | 多租户、权限、插件/记忆、HITL、子 Agent | 已交付 |
| **0.3.0** | 评测、A/B、成本归因、Capability HTTP 集成 | **当前** |
| 0.4.0 | 租户业务知识库 RAG、业务知识图谱、可靠执行补齐 | 规划中 |
| 0.5.0 | 可观测、Console 深度调试、生产化部署与安全 | 规划中 |
| 1.0.0 | API 稳定承诺与生产验收 | 规划中 |

## 3. 其他项目当前里程碑

- **Ouroboros 2.0.0**：Python 导入包名统一为 `ouroboros`；此前的运行循环、插件/工具/技能、记忆和评测能力仍按框架独立版本线维护。多智能体协同属于远期版本。
- **Capability Registry 0.3.0**：Local Tool CRUD、MCP Provider 同步、HTTP API Tool 与 Platform Runtime 集成已交付；Discovery/Permission 属于后续规划。

## 4. 规划使用约定

1. “已交付”仅指当前仓库代码和项目 README 能证明的行为；文档设计稿和框架协议不自动代表平台功能已经接通。
2. 未来版本范围是方向性规划，实施前可调整；接口、安全边界或运行行为变更时同步对应子项目文档。
3. 旧 V0.1/V0.2/V0.3/V1.0/V1.1 等命名只用于解释历史规格，不再覆盖当前 0.x 平台版本。

PlatformAgent 0.4.0 的图谱范围是从租户文档抽取业务实体、关系和来源证据；不包含从对话构建个人
Memory Graph。详见 [知识图谱与知识检索设计](./platformagent/知识图谱与知识检索设计.md)。
