# PlatformAgent 版本规划

> 本文只描述 PlatformAgent 业务平台线；跨项目的版本号和兼容边界见仓库根 [VERSIONS.md](../../VERSIONS.md)。
> 现状基线：2026-10-14。历史编号仅用于追溯旧文档，不再作为当前路线图主版本。

## 1. 当前项目边界

PlatformAgent 包含 FastAPI 业务后端和随平台交付的 React Console。它依赖 Ouroboros 2.0.0；
Capability Registry 0.3.0 由后端经共享密钥保护的 HTTP API 集成。各自的版本号不可互换。

## 2. 路线图

| 平台版本 | 范围 | 状态 |
|---|---|---|
| 0.1.0 | 单 Agent HTTP 闭环、Builtin Tool、Working Brain、同步/SSE Run | 已交付 |
| 0.2.0 | 多租户、JWT、RBAC/Grant、Skill/Tool 装配、pgvector 记忆、HITL、checkpoint、子 Agent、审计 | 已交付 |
| **0.3.0** | Golden Set/Judge、在线反馈、A/B 实验、分级模型路由、缓存与成本归因；接入 Capability API/MCP Tools | **当前** |
| 0.4.0 | 租户业务知识库：Knowledge/Retriever、RAG 摄取/检索/来源证据、业务知识图谱、可靠运行补齐 | 规划中 |
| 0.5.0 | OTel/指标、运行查询与可视化控制台、Playground、生产安全和部署、进程外任务调度 | 规划中 |
| 1.0.0 | 对外 API 稳定策略、兼容性承诺和生产验收 | 规划中 |

## 3. 已提前交付的能力

- 持久化 checkpoint 原属于后续可靠性范围，因 HITL `resume` 需要而在 0.2.0 提前交付。
- 评测、A/B 与成本功能从旧路线的 V1.1 前移为当前平台 0.3.0。
- Capability Registry 的 API Tool/MCP Tool 接入属于当前已实现能力，不等于 Platform 内部自建知识库。

## 4. 尚未交付的界限

当前有框架 Knowledge/Retriever 协议，但业务端未接入知识摄取和检索；当前只有个人向量长期记忆，没有业务知识图谱。
0.4.0 规划的图谱是从租户知识文档抽取的业务实体/关系；不是对话中抽取用户偏好的 Memory Graph。
具体设计见[知识图谱与知识检索设计](./知识图谱与知识检索设计.md)。
当前 Run SSE 和 checkpoint/HITL 不意味着已有通用 pause/cancel 接口或 DAG Console。0.5.0 的生产目标也不代表
已有 Kubernetes、高可用数据库、外部任务队列或完整可观测基础设施。

详细代码分层见[业务层详细设计](./业务层详细设计.md)；在线 API 以[API 文档](./API文档.md)中的 `/docs` 入口为准。
